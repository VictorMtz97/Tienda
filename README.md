Programa con Tkinter

Simulacion de una tienda desarrollada en Python utilizando Tkinter que simula una tienda con registro de usuarios, productos y una caja que genra un ticket con pdf


Esta aplicación te permite:

En una ventana principal: ingresar con usuario y contraseña por defecto estan vacios los campos.

En la siguiente ventana principal: Se muestran varias pestaas en las cuales podras realizar diferentes acciones:

*Ventas: Añadir productos que tengan stock y esten registrados al final podras eliminar o agregar productos al carrito y generar un ticket

*Reportes: Podras mostrar la carpeta donde se guardan los tickets y seleccionar uno para poder abrirlo.

*Productos: En esta pestaña se agregan los prodcutos con el precio, cantidad y stock, al igual que poder eliminarlos si no tienen stock

*Registrar usuarios: Se agregan usuarios y se asigna un rol, al igual que poder eliminarlo

Tecnologías utilizadas:

Python 3

Tkinter (Interfaz gráfica)

webbrowser (Mostrar el pdf por web)
